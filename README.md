# Intellium

Intellium is an Intel optimization that improved performance compared to vanilla performance.

Exist on Modrinth link: https://modrinth.com/mod/intellium

## Features
- Improves performance on Intel CPUs
- Fabric 1.21.5, 1.21.1, 1.20.4 compatible
- Configurable options via GUI

## Installation
- Place the mod jar in your `mods` folder.
- Requires **Fabric loader**/Quilt 0.16.14, **Fabric API** 0.124.0+, **Cloth Config API** 18.0.145+ and **Mod Menu** 14.0.0-rc.2.
